# 公务员岗位智能筛选系统

纯前端（HTML5 + CSS3 + 原生 JavaScript）的公务员 / 事业单位招聘岗位智能筛选工具。导入 Excel 岗位表，填写自身条件，系统逐岗位判定 **✅ 符合 / ❌ 不符合 / ⚠️ 需人工核实**，并给出逐字段判断依据。

新粗野主义（Neo-Brutalism）界面，数据全部在本地浏览器处理，不上传服务器。

## 在线使用

通过 GitHub Pages 打开后自动载入内置的 2027 年度国考岗位数据（19,426 条），也可重新导入自己的 Excel / CSV 文件。

## 功能

- **智能资格匹配**（默认模式）：填写专业（关键词/代码，模糊或精确）、学历、学位、政治面貌、基层工作年限、服务基层项目经历，自动判定每个岗位能否报考
  - 专业**分层匹配**：识别「本科：…；研究生：…」分段要求，按用户学历选择对应段判断
  - 学历层级集合判断（仅限/及以上/或），非关键词包含
  - 「与最高学历相对应的学位」按学历↔学位对应关系联合判断
  - 预备党员 vs 党员岗位、空白单元格、无法解析的条件 → 标记 ⚠️ 需人工核实，不误判
- **原始条件筛选**：按 Excel 原始字段文本直接子串过滤
- **结果表格**：分页 / 多列排序 / 每列过滤 / 横向滚动 / 长文本展开 / 点击行查看逐字段判断依据
- **导入**：支持 .xlsx / .xls / .csv，自动识别表头与六个核心字段，支持手动字段映射、多 sheet
- **导出**：筛选结果（含匹配状态与原因）导出为 Excel
- **筛选方案**：保存 / 恢复条件组合（localStorage）

## 本地运行

直接双击 `index.html` 即可（file:// 协议下自动加载内置数据不可用，请手动导入文件）；或起个静态服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 技术

- 无框架、无构建步骤；SheetJS（`libs/xlsx.full.min.js`）已本地化，可完全离线运行
- 唯一外部依赖是 Google Fonts（CDN），离线时自动回退系统字体

## 数据来源

`data/2027年度国考岗位.csv`：中央机关及其直属机构 2027 年度考试录用公务员招考简章（19,426 条，公开数据）。
